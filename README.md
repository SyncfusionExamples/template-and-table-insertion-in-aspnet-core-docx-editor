# Template and Table Insertion in ASP.NET Core DOCX Editor

## Introduction

This sample demonstrates template insertion and custom table management using sidebar panels in the Syncfusion® [ASP.NET Core Document Editor](https://www.syncfusion.com/document-processing/word/word-processor/aspnet-core/document-editor). It showcases how to insert predefined templates, manage table creation from a sidebar panel, and navigate through document bookmarks seamlessly.

## Features

The sample provides three main capabilities accessible from the header toolbar:

### 1. Insert Template
Insert predefined document templates directly into the document at the cursor position with a single click. Templates are loaded and inserted seamlessly with source formatting preserved.

### 2. Navigate to Topics
Jump to specific sections within the document using bookmarks. Navigate through document sections quickly without manual scrolling.

### 3. Insert Table
Create and customize tables with the following capabilities:
- Add/Edit/Delete rows with custom data
- Configure column visibility (Show/Hide columns)
- Export table as formatted HTML
- Insert tables into document with professional styling

## Prerequisites

Install the following before running the sample:

1. .NET 10.0 SDK
2. Visual Studio 2026 or Visual Studio Code
3. A valid Syncfusion license key for the Syncfusion components
4. Modern web browser (Chrome, Firefox, Edge, Safari)

## How to Run the Sample

1. Open a terminal in the project directory
2. Restore NuGet packages:
```bash
dotnet restore
```

3. Build the project:
```bash
dotnet build
```

4. Run the application:
```bash
dotnet run
```

5. Open your browser and navigate to:
```
http://localhost:5000/syncfusiondemo
```
